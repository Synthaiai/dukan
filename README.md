# دكان — الموقع التعريفي

موقع ساكن (static) بلا أي build step وبلا مكتبات خارجية: `index.html` + `styles.css` + `main.js`.
عربي بالكامل، RTL، ومبني للموبايل أول شي.

```
index.html            الصفحة
styles.css            التصميم (كل الألوان والقياسات بمتغيرات CSS بأول الملف)
main.js               الإعدادات + التفاعلات (أقل من 9 كيلوبايت)
favicon.svg           أيقونة التبويب — شعار «دكان» أبيض على مربع أحمر
apple-touch-icon.png  أيقونة الآيفون 180×180
assets/og-image.svg   صورة المشاركة (المصدر)
assets/og-image.png   صورة المشاركة 1200×630 (اللي تنشرها المنصات)
robots.txt, sitemap.xml
tools/make_assets.py   سكربت يولّد الأيقونة وصورة المشاركة من ملف الخط
thmanyah typeface/     ملفات خط ثمانية (المستخدم منها: Regular / Bold / Black)
```

---

## 1. تغيير الأسعار والرقم ومدة التسليم

كلها بمكان واحد: كائن `config` بأول [main.js](main.js).

```js
const config = {
  phone: '9647817631103',              // رقم الواتساب بصيغة دولية بلا +
  phoneDisplay: '+964 781 763 1103',   // الشكل المعروض بالصفحة
  instagramHandle: '@dukan.platform',
  hours: 48,                           // مدة التسليم بالمعدّل
  prices: { basic: 35, pro: 55 }       // بالألف دينار / شهرياً
};
```

الجافاسكربت يحقن هذي القيم بكل مكان يحمل `data-cfg` (الأرقام تتحول تلقائياً لأرقام عربية:
٣٥، ٥٥، ٤٨)، ويبني روابط الواتساب مع الرسالة الجاهزة بكل زر يحمل `data-wa`.

**مهم:** نفس القيم مكتوبة بالـ HTML كنسخة احتياطية حتى الصفحة تشتغل صح إذا الجافاسكربت
ما اشتغل (وحتى محركات البحث تقراها). إذا غيّرت السعر بالـ `config`، دوّر عليه بالـ HTML
وغيّره هم — أو خلّه، لأن الجافاسكربت يكتب فوقه على كل حال.

رسائل الواتساب الجاهزة:

| الزر | `data-wa` | الرسالة |
|---|---|---|
| كل أزرار «ابدأ» | `default` | هلو دكان 👋 أريد أسوي متجر إلكتروني لبراندي |
| اختر الأساسية | `basic` | هلو دكان 👋 مهتم بالباقة الأساسية (35 ألف) |
| اختر الاحترافية | `pro` | هلو دكان 👋 مهتم بالباقة الاحترافية (55 ألف) |

## 2. إضافة متجر حقيقي لقسم «من شغلنا»

حالياً القسم يعرض ٣ نماذج توضيحية مكتوب عليها «نموذج توضيحي»، وزر «شوف المتجر» معطّل.
**لا تسمّي أي نموذج باسم زبون حقيقي.**

بقسم `id="work"` بالـ HTML، لكل بطاقة:

1. بدّل اسم المتجر بـ `<div class="work-meta"><b>…</b>`.
2. شيل `<span class="tag">نموذج توضيحي</span>` أو بدّله بتصنيف المتجر (مثلاً `أزياء`).
3. بدّل الزر المعطّل برابط حقيقي:

```html
<!-- من -->
<button class="work-link" type="button" disabled>شوف المتجر</button>
<!-- إلى -->
<a class="work-link" href="https://example.com" target="_blank" rel="noopener">شوف المتجر</a>
```

4. غيّر محتوى شاشة الموبايل (أسماء المنتجات والأسعار) داخل `.device-mini`.
   الثيمات الجاهزة: بلا صنف = فاتح، `theme-night` = غامق، `theme-warm` = بيج.

## 2.1 صور المنتجات داخل شاشات الموبايل

صور المنتجات مرسومة كـ SVG جوّا نفس الصفحة (بمجموعة `<symbol>` أول الـ `<body>`، معرّفاتها
تبدي بـ `p-`: `p-jacket`، `p-bag`، `p-perfume` … ). ما نستخدم صور ستوك حتى ما تصير مشاكل
ترخيص، والرسم SVG يعني حجم شبه معدوم ووضوح كامل على أي شاشة.

**تبديل رسم برسم ثاني:** غيّر `href` بالبطاقة:

```html
<span class="ui-thumb"><svg aria-hidden="true" viewBox="0 0 64 60"><use href="#p-bag"/></svg></span>
```

**تحط صورة حقيقية بداله:** بدّل الـ `<svg>` بـ `<img>`:

```html
<span class="ui-thumb"><img src="assets/products/jacket.webp" alt="" loading="lazy"></span>
```

وضيف بـ `styles.css`:

```css
.ui-thumb img { inline-size: 100%; block-size: 100%; object-fit: cover; }
```

خلّي الصور مربعة تقريباً وبعرض ~300px و WebP حتى ما تأثر على سرعة الصفحة.

## 3. تشغيل قسم آراء الزبائن

القسم مبني بس **مطفي** لحد ما تجي اقتباسات حقيقية بإذن أصحابها.

1. بالـ HTML، جوّا قسم `id="pricing"`، شيل `hidden` وبدّل `data-enabled="false"` لـ `"true"`.
2. بأول [main.js](main.js) اكو مصفوفة `testimonials` داخل تعليق — فكّ التعليق وعبّيها
   بأسماء واقتباسات حقيقية.
3. ما ننشر أي اقتباس بلا إذن صريح من صاحبه.

## 4. الأسئلة الشائعة — راجعها قبل النشر

أول ثلاث إجابات (الدومين، كلفة التأسيس، إيقاف الاشتراك) مكتوبة **كسياسة مقترحة**
مو كحقيقة مؤكدة، لأنها قرارات شغل إنت تحددها. اكو تعليق يذكّرك بيها فوق قسم
`id="faq"` بالـ HTML. تأكد إنها تطابق اللي تشتغل بيه فعلاً وعدّلها إذا تحتاج.

## 5. توليد الأيقونة وصورة المشاركة من جديد

الشعار مشكّل بـ HarfBuzz مع خاصية `swsh` (هي اللي تنطي الذيول الممدودة على الكاف والنون)،
ومصدّر كمسارات حقيقية — يعني الأيقونة وصورة المشاركة ما تحتاج الخط حتى تنعرض صح.

```bash
pip install uharfbuzz fonttools brotli pillow freetype-py
python tools/make_assets.py
```

يولّد: `favicon.svg`، `apple-touch-icon.png`، `assets/og-image.svg`، `assets/og-image.png`.
إذا غيّرت الدومين، غيّر النص بدالة `og_layout` داخل السكربت.

## 6. النشر على Cloudflare Pages

**من لوحة التحكم (الأسهل):**

1. Cloudflare Dashboard ← Workers & Pages ← Create ← Pages ← Connect to Git.
2. اختر هذا الريبو.
3. **Framework preset:** None · **Build command:** خلّيه فارغ · **Build output directory:** `/`
4. Save and Deploy.

**أو من الطرفية:**

```bash
npx wrangler pages deploy . --project-name=dukan-iq
```

**بعد أول نشر:**

- إذا غيّرت الدومين، بدّل `https://dukan-iq.pages.dev/` بكل من: `<link rel="canonical">`،
  وسوم `og:` و`twitter:`، الـ JSON-LD، و`sitemap.xml` و`robots.txt`.
- تأكد إن مجلد `thmanyah typeface/` منشور وياه (منه تنحمّل ملفات الخط).

## 7. ملاحظات تقنية

- **الخط:** ثمانية سانس — Regular (400) و Bold (700) و Black (900) بس. Regular و Black
  محمّلين مسبقاً (`preload`). المسار يحتوي مسافة فمشفّرة `thmanyah%20typeface/…`.
- **ارتفاع السطر:** حبر خط ثمانية يطلع برّا صندوق السطر المعلن (yMax 1289 / yMin −629 على
  1000 وحدة)، فقياسات `line-height` بالموقع مأخوذة من قياس الجمل الفعلية: `h1` يحتاج 1.21،
  الـ `h2` لحد 1.44، الـ `h3` لحد 1.55. أي قيمة أقل تخلي السطور تتداخل.
- **الألوان:** كل الألوان متغيرات بأول `styles.css`. `--meta` و`--wa-deep` موجودين
  لأن `--ink-3` على الورقي و«الأبيض على أخضر واتساب» ما يوصلون لنسبة التباين 4.5:1.
- **الحركة:** كل الحركات تنطفي مع `prefers-reduced-motion`، والمحتوى يظهر كامل بلا جافاسكربت.
- **التحليلات:** كل زر مهم عنده `data-cta`. الجافاسكربت يرسل الحدث لـ `gtag` أو `dataLayer`
  أو `plausible` إذا موجودين، وبكل الأحوال يطلق حدث `dukan:cta` على `window`.
- **التخطيط:** كله بخصائص منطقية (`inline-size`، `inset-inline-start` …) عدا أزرار جانب
  الموبايل بالماكيت — هذيچ `left/right` فيزيائية عمداً حتى ما تنعكس.
